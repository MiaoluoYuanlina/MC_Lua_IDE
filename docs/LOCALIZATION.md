# IDE language support

The administrator IDE follows `Minecraft.options.languageCode`; it does not change the game language or server configuration. `zh`, `zh_*`, `lzh` and `yue` variants use Chinese, `ja`/`ja_*` use Japanese, and other languages currently fall back to English.

`LuaUiText` is client-only. Its English presentation dictionary is `assets/mc_lua_ide/i18n/en_us.json`. Chinese presentation strings are the canonical lookup keys. Add translations there and explicitly wrap new presentation literals with `LuaUiText.text(...)`, or use the two-argument form for context-sensitive wording. Never translate resource IDs, persistence keys, network fields, Lua source or user-entered content. Minecraft's standard key-binding translations remain in `lang/en_us.json` and `lang/zh_cn.json`.

`scripts/localize-ide.mjs` is an optional mechanical migration for known literals in presentation classes. It skips Java comments, character literals, text blocks and already localized calls. Static navigation/enum labels remain canonical and are translated by their accessors so switching language does not freeze the original language. Review new use sites rather than running a replacement over arbitrary implementation files.

Built-in API presentation is handled separately from raw metadata. English summaries and parameter help do not replace the analyzer's raw type hints. Detailed notes without a dedicated translation retain a clearly labeled Chinese original instead of discarding safety constraints or event payload fields. Third-party APIs/pages use the translations supplied by their owner and are rebuilt when the selected game language changes. Example code and its literal values are not rewritten by localization.

The bundled Markdown guide has Chinese, Japanese and English editions. New substantive features should update all three. Some server-originated diagnostics, dynamic codec descriptions and third-party content can still contain their original language. `i18n/ja_jp.json` maps the canonical English presentation strings to Japanese (with optional direct Chinese keys); the two-step lookup also handles existing two-argument `LuaUiText.text` calls without rewriting technical IDs or Lua examples.

Pinyin indexes may be cached, but every matching path must gate their use on `LuaUiText.chinese()`. Do not remove indexes when entering English: returning to Chinese must work without rebuilding or losing preferences. `LuaApiDocsOverlay` also hides the toggle, widens the input and uses the same bounds for painting and hit testing.

Japanese search uses `JapaneseSearchIndex`: search-only NFKC normalization, katakana/hiragana equivalence, mapped kana-to-romaji, common spelling aliases and a bounded cache. Compatibility normalization is appropriate for these search keys, not for rewriting user data; see [Unicode normalization](https://unicode.org/reports/tr15/). Kana contractions, small tsu, long vowels and combining/halfwidth dakuten retain original UTF-16 ranges for highlights. Unknown kanji/emoji create barriers rather than disappearing between searchable words. Only kana and the domain readings explicitly supplied in `i18n/ja_readings.json` are converted: this is not a full Japanese morphological dictionary and must never use Chinese Han readings. Extend the dictionary with whole compounds where a single character has context-dependent readings.

Japanese API search has a separately persisted `apiDocs.navigation.romaji` preference. It never overwrites `pinyin`. Disabling romaji retains literal ID/name search and kana equivalence; English hides both toggles. Server annotations are retained but do not suppress available native Japanese names, and known registry-type captions use the current UI language.

Run `gradlew japaneseSearchSmoke localizationSmoke apiSearchFoldingSmoke analyzerSmoke ideSessionSmoke` to check locale variants, cached-index policy, resource coverage, kana/romaji/dictionary search, highlight offsets, actual toggle clicks, preferences, translated guides, external translations, Chinese restoration and editor regressions.
